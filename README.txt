SOMYA SHUKLA — PORTFOLIO STARTER

FILES:
- index.html: page content
- style.css: design and responsive layout
- script.js: mobile menu and current year

RUN ON YOUR LAPTOP:
1. Download and extract the ZIP.
2. Open Visual Studio Code.
3. Select File -> Open Folder and choose this folder.
4. Open index.html.
5. If Live Server is installed, right-click index.html -> Open with Live Server.
   Otherwise, double-click index.html to open it in a browser.

BEFORE SHARING WITH CLIENTS:
- Replace sample project details with your real projects.
- Replace the GitHub profile links with direct repository links where possible.
- Add your professional email only if you want it public.
- Keep only skills you can confidently discuss.
- For internship/organization projects, share only information you have permission to disclose.

PUBLISH WITH GITHUB PAGES:
1. Create a new public GitHub repository for this portfolio.
2. Upload index.html, style.css, and script.js (README is optional).
3. In the repository, open Settings -> Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select main branch and /(root), then Save.
6. Wait for GitHub Pages to publish and open the URL shown there.
