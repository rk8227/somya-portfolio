FEATURED PROJECT

AeroPass

Digital Aerodrome Entry Permit (AEP) Application System

AAI React.js Web Application

About the project

AeroPass is a digital application system related to the Aerodrome Entry Permit (AEP) application process. The system includes an application workflow designed to help users submit application information and documents.

Key system features

  • Multi-step AEP application form.
  • Document, photograph and signature upload.
  • Application status tracking.
  • Approval and rejection workflow for the authorised role.
  • BCAS-format application PDF and print functionality.
  • Email OTP-based password reset.

Experience: Worked with this system during my IT apprenticeship at Airports Authority of India (AAI). I will describe my personal contribution accurately during interviews.
